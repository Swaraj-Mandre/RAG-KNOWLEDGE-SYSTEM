RAG-based Knowledge System
- Build an AI-powered system that can answer questions using your own documents

Document → Document Loader → Chunk → Embedding → Vector DB → Query → Retrieve → LLM → Answer
(LangChain)                 (FAISS)                                 (Gemini-2.5-Flash)
Two sub-pipeline exist in every RAG System
A. Ingestion Pipeline (offline)
Documents → Load Documents → Chunk Documents → Generate Embedding → Store in Vector DB
B. Query Pipeline (runtime)
User Query → Query Embedding → Vector Similarity Search → Top Relevant chunks → Inject Context into Prompt → Gemini 2.5 Flash → Final Answer
